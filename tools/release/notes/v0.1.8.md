## Downloads

| Platform | File |
|---|---|
| Linux x86_64 (glibc 2.35+: Ubuntu 22.04, Debian 12, Fedora 36 or newer) | `cadrs-v0.1.8-x86_64-linux.tar.gz` |
| Windows x86_64 (Windows 10 or 11) | `cadrs-v0.1.8-x86_64-windows.zip` |

Each archive holds the executable, its `libraries/` folder (the built-in symbols, footprints and 3D models), the README and the licenses. Nothing needs installing: unpack it and run `cadrs` (Linux) or `cadrs.exe` (Windows), keeping `libraries/` beside it. `SHA256SUMS.txt` has the files' checksums.

On Linux, the app needs a Vulkan-capable GPU driver, and ALSA and udev (present on desktop distributions). The Windows build isn't code-signed, so SmartScreen may warn the first time: choose **More info › Run anyway**.

Documents are saved in `~/.local/share/cadrs/` on Linux and `%APPDATA%\cadrs\` on Windows.

## What's new since v0.1.7

- **Updates from inside the app.** At startup the app checks GitHub for a newer release and offers it with its notes and an **Upgrade** button, which downloads it, swaps it in place and restarts. `CADRS_NO_UPDATE_CHECK=1` turns the check off. The version now shows in the documents page's top bar.
- **Thread.** A modelled ISO or ANSI screw thread on a shaft or in a hole: coarse, fine or a custom size and pitch, fitted to the picked edge, blind or up to the end, right- or left-hand.
- **Dark mode.** A light / dark / system toggle at the top right, saved in your preferences. The PCB Studio schematic gets a dark theme of its own, with net highlighting on hover.
- **CAM studios (early preview).** Jobs, machines and setups; milling (bore, 2D profile with tabs, adaptive clearing, parallel finishing), plasma cutting with kerf compensation, back plot, stock verification and posting G-code (Fanuc, LinuxCNC QtPlasmaC). Still in progress.
- **Copy values.** Mass properties values can be selected and copied, with a copy icon on hover, and copying now reaches the system clipboard.
- **Modelling.**
  - Merge scope (Extrude, Revolve) stays as you set it, has a **Clear all** button and highlights its parts. Merge scope and Transform fields pick whole parts.
  - Extrude's Add/Remove switch flips the direction into or away from the material, and an Up to target behind the start flips the extrude.
  - Boolean shows tools and targets that no longer exist as "Missing Part".
  - Editing a Plane no longer adds the plane to its own entities; Plane features can be shown and hidden from the feature list.
  - Dropping a feature on its own place in the feature list no longer moves it to the bottom.
- **Sketch.** Hold Alt to draw a square rectangle.
- **Assemblies.** Delete removes the selected mate.
- **Drawings.** Tangent edges lying on a silhouette are drawn as outlines (#56).
- **Frame stats** are compact by default.
