## Downloads

| Platform | File |
|---|---|
| Linux x86_64 (glibc 2.35+: Ubuntu 22.04, Debian 12, Fedora 36 or newer) | `cadrs-v0.1.6-x86_64-linux.tar.gz` |
| Windows x86_64 (Windows 10 or 11) | `cadrs-v0.1.6-x86_64-windows.zip` |

Each archive holds the executable, its `libraries/` folder (the built-in symbols, footprints and 3D models), the README and the licenses. Nothing needs installing: unpack it and run `cadrs` (Linux) or `cadrs.exe` (Windows), keeping `libraries/` beside it. `SHA256SUMS.txt` has the files' checksums.

On Linux, the app needs a Vulkan-capable GPU driver, and ALSA and udev (present on desktop distributions). The Windows build isn't code-signed, so SmartScreen may warn the first time: choose **More info › Run anyway**.

Documents are saved in `~/.local/share/cadrs/` on Linux and `%APPDATA%\cadrs\` on Windows.

## What's new since v0.1.5

- **A geometry kernel in pure Rust.** OpenCASCADE is gone: booleans, fillets and chamfers, shells, offsets, sweeps, STEP/IGES and meshing all run on cadrs' own kernel.
  - Booleans handle near-coincident faces, cones and tori, touching and multi-solid cases from real documents.
  - Fillets and blends with far fewer fallbacks, computed in parallel.
  - Real-world test documents rebuild in about half the time.
  - The kernel runs in a process of its own: a kernel crash costs a rebuild, not the app.
- **Modelling.**
  - Shell: outward walls round over tangent openings, curved faces work, and the dialog previews with an arrow.
  - Loft lines its sections up by every start point.
  - Section view: rotation about the arrow's origin, closed caps while dragging.
  - Assemblies: rotate with the triad's arcs, with a snap increment in Preferences.
- **Sketches.**
  - Box selection previews what it selects; dragging one of several selected entities moves them all.
  - Mirror: box-select the entities to mirror, no duplicate copies, step prompts.
  - A drag can flip a shape inside out.
  - The Construction button toggles the selection, like Q.
- **Import and export.** STEP colours are kept; large STL meshes import in seconds instead of hanging.
- **Faster with big documents.** Idle frames in large Part Studios and assemblies do no per-frame work; picking on big faces is faster. F12 shows the frame rate and where each frame's time goes.
- **Windows.** The app icon in `cadrs.exe`, sharp in the title bar and taskbar; the window title says what is open.
- **Interface.** A UI scale preference (75–200 %); shortcuts follow the keyboard layout, not the physical key; long file names no longer overflow the Import dialog.
- **MCP server.** Assembly tools (insert instances, read assemblies, delete tabs), document versions, close-up screenshots and frame statistics.
- **Install from source.** `cargo install-local` installs a checkout with a launcher entry on Linux, macOS and Windows.
