## Downloads

| Platform | File |
|---|---|
| Linux x86_64 (glibc 2.35+: Ubuntu 22.04, Debian 12, Fedora 36 or newer) | `cadrs-v0.1.7-x86_64-linux.tar.gz` |
| Windows x86_64 (Windows 10 or 11) | `cadrs-v0.1.7-x86_64-windows.zip` |

Each archive holds the executable, its `libraries/` folder (the built-in symbols, footprints and 3D models), the README and the licenses. Nothing needs installing: unpack it and run `cadrs` (Linux) or `cadrs.exe` (Windows), keeping `libraries/` beside it. `SHA256SUMS.txt` has the files' checksums.

On Linux, the app needs a Vulkan-capable GPU driver, and ALSA and udev (present on desktop distributions). The Windows build isn't code-signed, so SmartScreen may warn the first time: choose **More info › Run anyway**.

Documents are saved in `~/.local/share/cadrs/` on Linux and `%APPDATA%\cadrs\` on Windows.

## What's new since v0.1.6

- **Open a document from the command line.** `cadrs <file.cadrs>` (or `cadrs --open <file.cadrs>`) opens a native document.
- **Smoother over time.** The viewport no longer slows down the longer the app runs (light clustering is off).
- **Fillets and chamfers.**
  - Fillets cap their ends where the end faces only touch, and weld across a narrow face.
  - A chamfer meeting a fillet at a convex corner fills the mitre round it.
  - Tangent chains stop where a concave edge runs on into a convex one.
- **Kernel.** Faces on one surface merge only when the merged face's loops don't cross.
- **Mate connectors.** "Between" on a flat face projects onto its exact plane.
- **Onshape import.** Fixes for edges of operations whose faces all merged into earlier ones, and for swept faces' curve ids.
